# Publication plan: Psychill

Status: draft. Nothing in this folder has been posted, published or announced.

## Before publishing

1. Listen to the parts in a real instrument. No human listening audition was performed for this build.
2. Choose a license and add a LICENSE file. None is set today.
3. If the pack will be sold, check the terms of the store you plan to use.

## GitHub Pages

1. Repository Settings, Pages, deploy from the `main` branch, folder `/` (root). Only the repository owner can do this.
2. Wait for the build, then open https://mizcausevic-dev.github.io/psychill/ and check that `index.html` loads and the preview plays.
3. Treat the address as live only after it responds.

## Rollback

Revert the merge commit, or set the Pages source to none. The files are plain static files, so nothing else needs undoing.

## Draft material

`articles/` and `social/` hold drafts. They are not posted. Review each before posting under your name.
